wait

opcode 1 · 001stable

wait pol, src, idx, [rel]

Stall until the source equals pol: gpio = absolute GPIO idx, pin = input pin idx (relative to the in base), irq = IRQ flag idx (0-7; rel adds the SM number modulo 4). A satisfied `wait 1 irq` clears the flag.

in

opcode 2 · 010stable

in src, count

Shift count bits from src into ISR (direction from `.sm_config in_shift=`) and add count to the input shift count (saturating at 32). With autopush, push ISR when the count reaches the threshold, stalling while the RX FIFO is full.

out

opcode 3 · 011stable

out dst, count

Shift count bits out of OSR (direction from `.sm_config out_shift=`) to dst and add count to the output shift count. pc jumps; exec runs the data as an instruction next cycle. With autopull, refill OSR from the TX FIFO when the count reaches the threshold, stalling while it is empty.

push

pull

opcode 4 · 100stable

pull [ifempty], [mode]

Load OSR from the TX FIFO. ifempty: do nothing unless the output count has reached the pull threshold. block (default): stall while the FIFO is empty; noblock: copy X into OSR instead. With autopull on, a pull is a no-op while OSR is full.

opcode 5 · 101stable

mov dst, src

dst = op(src). op: ! or ~ inverts, :: bit-reverses. status is all ones while the selected FIFO's level is below N (`.sm_config status=`), else zero. mov isr/osr reset the matching shift count; exec runs the value as an instruction next cycle.

Notes

  • Overflow: none — every instruction fits in 16 bits.
  • operand is full for jmp, wait, in, out, mov, irq, set, nop. A new per-bit modifier there needs a wider field or a new format.
  • Headroom (bits left in the most tightly packed instruction): operand 0 of 8.
  • Opcodes: 0 of 8 free.
  • This is the RP2040 format, so it is fixed: words match pioasm (tests: pioscope/packs/pio/tests/test_encode.py).
  • An instruction memory of 32 words is shared by the block's four state machines; jmp targets are 5-bit absolute addresses.
