# Architecture study: PIO-style cores vs a software-allocated mesh (generated)

ISA pack: RP2040 PIO. Generated by `uv run piolab arch --write` from `piolab/packs/pio/arch/{workloads,architectures,cost}.yaml` and the programs in `piolab/packs/pio/programs/`. Do not edit by hand. Method and scope: [ADR-0007](../open_items/0007-architecture-study.md). Interactive view (architecture diagrams, utilisation heatmap, charts): open [arch-study.html](arch-study.html) in a browser. Terms, formulas and worked examples: [arch-guide.md](../arch-guide.md).

> **Status: analytic estimates.** Area constants are placeholders (see the sensitivity table). Activity figures are estimated from each program's static bit shares and a traffic load; they will be replaced by counters measured on the engine model. Allocation is static (load time) only. imem is flip-flops or IHP SRAM macros, whichever is cheaper for each configuration.

| `mesh_full` | mesh: pooled cores/banks/units/FIFOs, full crossbar, software allocation | 4 cores, 4x64w sram banks, 6 FIFOs, full xbar | 25,360 | 5.9 | 15% | 36% | 26% |
| `pio_shared` | PIO-style: one imem shared by all cores (RP2040), lean units; as SRAM it needs a port per core, so at most 2 cores | 4 cores x [no units], 128w shared flops | 50,432 | 11.7 | 40% | 21% | 16% |

- **tiles:** Tiny Tapeout tiles covered by the cells and macros at 100% density; real placement needs more. A 64-word SRAM macro is 236.8 um wide, wider than one tile (about 202 um).
- **overhead:** imem read ports, crossbar and allocation-config flops, as a share of total area.
- **allocated area:** the share of the area that is assigned to some program in a workload. **Active area:** the same, weighted by how busy the logic is (storage counts when allocated). Means are over all workloads.

## Sensitivity to the area constants

Baseline order (smallest first): `mesh_c2` < `pio_full` < `pio_lean` < `mesh_full` < `pio_shared`. Each constant scaled x0.5 and x2 on its own:

| constant | order at x0.5 | order at x2 | effect |
|---|---|---|---|
| `flop_bit` | pio_full < pio_lean < mesh_c2 < mesh_full < pio_shared | mesh_c2 < mesh_full < pio_full < pio_lean < pio_shared | **leader changes** |
| `mux2_bit` | mesh_c2 < mesh_full < pio_full < pio_lean < pio_shared | pio_full < pio_lean < mesh_c2 < mesh_full < pio_shared | **leader changes** |
| `core` | mesh_c2 < pio_full < pio_lean < mesh_full < pio_shared | mesh_c2 < pio_full < pio_lean < mesh_full < pio_shared | stable |
| `fifo_control` | mesh_c2 < pio_full < pio_lean < mesh_full < pio_shared | mesh_c2 < pio_full < pio_lean < mesh_full < pio_shared | stable |
| `unit_port_bits` | mesh_c2 < pio_full < pio_lean < mesh_full < pio_shared | mesh_c2 < pio_full < pio_lean < mesh_full < pio_shared | stable |
